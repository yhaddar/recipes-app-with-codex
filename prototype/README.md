# Recipe Manager Version 1 Prototype

This is the static HTML5/CSS3 prototype for Recipe Manager Version 1.

## Run locally

Open `prototype/index.html` directly in a browser, or serve the repository root with any existing local static-file server and open `/prototype/index.html`.

No package installation, build step, backend, JavaScript, database, or network access is required.

## Prototype scope

The prototype demonstrates the public Frontoffice, User Backoffice, Admin Backoffice, recipe and story flows, responsive layouts, native forms, and the CSS-only Login/Register switch. Authentication providers are represented by accessible icon-only controls; no real authentication or persistence is implemented.
